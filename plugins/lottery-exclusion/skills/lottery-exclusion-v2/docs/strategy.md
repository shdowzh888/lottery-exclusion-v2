# v2 排除法策略详解

## 一、核心思想

排除上一期号码 + 热度+遗漏加权 + 形态过滤。四步流水线：

```
历史数据 → 排除上期 → 热度加权评分 → 候选池 TOP12/14/16
   ↓
枚举 C(候选池, k) 组合 → 形态过滤 (和值/AC/跨度/奇偶) → 取评分最高
```

**predict 与 backtest 必须共用 `lotto_core.py` 同一套评分/选号函数**（v1 的教训：两份代码漂移后回测验证的不是线上策略）。

## 二、参数化

全部在 `config.json`：

| 区块 | 内容 |
|---|---|
| `games.*` | 号码池/开奖个数/接口/CSV 路径 |
| `strategy.exclusion_v2.front_recent_weights` | 前区 h30/h10/all = 1.0/0.5/0.2 |
| `back_recent_weights` | 后区 h10/all = 1.0/0.2 |
| `miss_weight_per_pool` | 遗漏回补 6.0/池大小 |
| `candidate_fallback_sizes` | [12, 14, 16] |
| `shape_filter.{ssq,dlt}` | **按彩种分别配置**的和值/AC/跨度/奇偶阈值 |
| `backtest` | train_window=500, seg_count=4, random_rounds=100 |

复式默认：ssq 7+2（C(7,6)·C(2,1)=14 注/28 元）；dlt 7+2（C(7,5)·C(2,2)=21 注/42 元）。

## 三、回测结果（2026-09-18，奖金枚举修复后首轮有效回测）

⚠️ v1 文档里的 13.82%/10.28% 等数字由复式奖金枚举 bug 产生（双色球漏算 i=6、两彩种注数只枚举 1/2~1/3），**全部作废**。以下为修正后、100 轮随机基线（seed=42）结果。

### 3.1 双色球 7+2（28 元，3005 期，0 期跳过）

| 指标 | v2 | 随机均值 | 随机 std | 95% 区间 | z |
|---|---|---|---|---|---|
| 前区平均命中 | 1.2839 | 期望 1.2727 | — | — | — |
| 蓝球覆盖开奖号 | 11.75% | 12.5% | — | — | — |
| 保本率（奖金≥28） | 12.85% | 13.39% | 0.66% | 12.21–14.81% | **−0.83** |
| 期望/期 | 5.94 元 | 26.94 元* | 171.67 | — | −0.12 |

\* 期望随机均值方差极大（头奖 500 万稀有事件主导），不适合作为对比指标，以保本率为主。

S3 分段（早/中/近/新）：−0.88 / −0.99 / +0.43 / −0.72 pp，**1 正 3 负，无一段 |z|≥1.96**。

### 3.2 大乐透 7+2（42 元，2424 期，0 期跳过）

| 指标 | v2 | 随机均值 | 随机 std | 95% 区间 | z |
|---|---|---|---|---|---|
| 前区平均命中 | 1.0392 | 期望 1.0000 | — | — | — |
| 后区至少中 1 | 32.22% | 33.33% | — | — | — |

S3 分段：−0.08 / −1.50 / +0.82 / **+3.30（z=1.98）** pp，2 正 2 负；最新段（22103–26106）恰好卡在显著边界，含新规首期 26014，样本仅 606 期，**只能作为观察点，不能当作有效证据**。

### 3.3 结论

- 两个彩种整体 z 均在 ±1.96 内：**v2 与随机选号没有统计显著差异，不具备可验证的中奖优势**。
- v2 的真实价值是：结构化排除上期号、形态约束、精确成本/对奖，而非提高期望。
- 单期结果主要靠运气；历史回测不预测未来（号码随机且规则会变）。

## 四、方法学（为什么这次结果可信）

| v1 问题 | v2 修法 |
|---|---|
| 复式奖金枚举注数错误 | 按 config 开奖个数枚举；注数不变量 C(nf,K)·C(nb,B) 内置断言 |
| predict/backtest 评分两套 | 全部走 lotto_core 单一实现 |
| 形态无解用未来数据回退 | 跳过并计 n_skip，本期 0 次 |
| 单种子单次随机 | 100 轮模拟，报均值/std/95% 区间/z |
| 全期用一套新奖表 | dlt 按期号自动切旧 9 奖级/新 7 奖级（默认 low 档） |

## 五、调参建议

| 场景 | 调整 |
|---|---|
| 形态无解频繁 | 扩 `candidate_fallback_sizes` 或放宽 `shape_filter.{game}` |
| 想换复式大小 | `predict/backtest --front-k/--back-k`，阈值按 n 自动适配 |
| 换思路验证 | 回测支持任意复式；也可改权重后重跑对比 z 值 |

## 六、已知局限

1. **无显著优势**：回测结论就是不显著，禁止对外宣称"策略有效"
2. **浮动奖用典型值**：ssq 一等 500 万/二等 15 万，dlt 一等 1000 万/二等 20 万，实际浮动
3. **8 亿高档与派奖活动**：需 `--pool high` 显式指定，默认 low；时效性派奖不建表
4. **福运奖**：ssq 3+0=5 元默认不计（状态随奖池启停），对奖加 `--fuyun`
5. **形态过滤的独立作用未做消融**：随机基线不含形态约束，无法区分收益来自权重还是过滤
